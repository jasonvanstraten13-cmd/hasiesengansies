# The Say and Play Space website

A static website for The Say and Play Space, which makes sensory boxes and toys inspired by paediatric therapists. It is plain HTML, CSS and JS with no build step.

Pages: `index.html`, `about.html`, `contact.html`, `thank-you.html`, `privacy-policy.html`, `terms-policy.html`.

## Deploy

On Netlify, create a new site from this repository with **Base directory** set to `say-and-play-space` and the publish directory set to `.`. This folder is separate from the Hasies en Gansies site at the repo root.

## Before going live

- [ ] Replace `REPLACE_WITH_FORMSPARK_ID` in `contact.html` with the real Formspark form ID.
- [ ] Fill in the highlighted placeholders in `privacy-policy.html` and `terms-policy.html`: legal name, registration number, registered address, contact email and privacy email.
- [ ] Swap the cover-cropped photos in `assets/boxes/` for full-resolution originals from Instagram (keep the same filenames).
- [ ] Confirm the theme names shown on the site (Under the Sea, Dino Discovery, Bug Hunt) and add any new themes.
- [ ] Once the domain is known, add canonical URLs, absolute `og:image` URLs and a `sitemap.xml`.

See `brand-spec.md` for brand assets, colours and fonts.
